# Security Policy

## Supported Versions

The following versions of the **Playroom Console Application** are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please report it responsibly:

1. **Do not** open a public GitHub issue for security vulnerabilities.
2. Report the issue via [GitHub Security Advisories](https://github.com/oleksandrmyhydiuk/oop_lab1_sem5/security/advisories/new) or by contacting the repository maintainer directly.
3. Include a clear description of the issue, steps to reproduce, and any potential impact.

All security reports will be reviewed promptly, and a fix or mitigation will be prepared as quickly as possible.
